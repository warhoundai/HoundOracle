# Data and model rights

Measurements and original code are distinct from external annotation/model rights.
FEVER annotation IDs and labels derive from Thorne et al. (NAACL 2018), Wikipedia
contributors, and the gold-evidence mirror associated with Atanasova, Wright and
Augenstein (EMNLP 2020), pinned in the dataset manifest. Original data uses applicable
Wikipedia terms / CC BY-SA 3.0; the mirror additionally declares GPL-3.0. Full text
and evidence are outside this source repository. These declarations are not a
professional clearance for public redistribution of data-derived artifacts/models.
No AVeriTeC data was used. No downloaded model weights are bundled. Public release
remains blocked on the stated quality, comparison and rights gates.
