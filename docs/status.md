# Execution status

## Implemented locally

- Python package, CLI and SDK; typed claims and strict cache equivalence.
- SQLite FTS discovery, versioned evidence, provenance grouping, exact spans,
  dependency invalidation and conditional source refresh.
- Deterministic semantic compiler, symbolic Boolean/unit/date checks, trainable
  logistic aggregator; research-only local NLI interface.
- Calibrated-decision gate with default abstention; no production calibration claim.
- Authenticated single-tenant REST, stdio MCP, durable cooperative jobs.
- Bounded HTTP retrieval and optional HoundSearch adapter.
- Opt-in signed S3 snapshot library; no cloud infrastructure provisioned.
- Automated tests, synthetic benchmark, source-linked research notes and protocols.

## Not complete / not qualified

- Full literature/implementation review, professional licensing review and complete
  research ablations; source retrieval and method inspection are initial research.
- Unrestricted natural-language extraction, entity disambiguation, temporal quantity
  scope, quantifiers, arbitrary structured records or broad multi-hop verification.
- Trained/qualified compact NLI, neural aggregator, NNUE, graph-aware model, learned
  retrieval policy, Gemini fallback, or independent real-world benchmarks.
- Live FIRE reproduction, current search-provider pricing/terms validation and
  end-to-end HoundSearch integration against a running deployment.
- Central account API, quarantine curator workflow, DynamoDB/Lambda infrastructure,
  fleet-wide reservations, snapshot revocation feeds and multi-tenant service.
- Persisted search frontier for exact resume, enforced OS-level wall-time sandbox,
  distributed workers, automated periodic refresh scheduling.
- Public repository release, OPS publication, production readiness or performance
  advantage. Existing released repositories and OPS have not been modified.

The approved AWS $450 / GCP $150 experiment caps and $25/month central target are
retained. No billable cloud experiment, paid search or deployment was initiated.
Cloud account access and current aggregate spend have not been validated; no claim
is made that account-wide spending limits are enforced by the local query budget.

## 2026-11-16 follow-up

The larger authorized live Gemini comparison ran on 48 fresh questions; its
planned replication was incomplete after provider/runtime failures. Lower scoped
model-token cost is supported, while all-in cost, reliable latency gains, coverage
noninferiority and broad factual confidence remain unqualified. See

exact evaluator reuse, a measured two-thread runtime option, citation validation
and per-query failure accounting. Production and public-release gates stay closed.
