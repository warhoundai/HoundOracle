Architecture

Verification infrastructure,
running on your machine.

HoundOracle is a verification engine for agent workflows. Its local SQLite evidence store records source versions, timestamps, exact passages and dependencies. Optional internet retrieval runs through self-hosted search and existing WarHound adapters.

A bounded evidence workflow

  1. Compile the exact proposition and check local evidence.
  2. Retrieve permitted sources within explicit request, time and cost limits.
  3. Evaluate passages with deterministic checks or an opt-in local semantic model.
  4. Check contradictory evidence, provenance, freshness and calibrated acceptance.
  5. Return a verdict with citations, diagnostics and failure reasons.

Local model files are explicitly installed and integrity-pinned. Runtime inference requires no paid model fallback. Web search still requires internet access and access to permitted sources. Similar wording does not authorize cached-answer reuse.

Developer quickstart

One engine. Three integration paths.

git clone https://github.com/warhoundai/HoundOracle.git
cd HoundOracle
uv sync --extra dev --extra api --extra mcp
uv run houndoracle --database oracle.sqlite verify \
  'Was Widget released in 2024?'

This illustrative query returns MAYBE without qualifying evidence and calibration. It is not a live verified claim.

from houndoracle import Oracle, Store

oracle = Oracle(Store("oracle.sqlite"))
result = oracle.verify("Was Widget released in 2024?")
print(result.decision, result.reason, result.citations)

Questions before you build

Can HoundOracle run fully locally?

Yes. The Python engine, SQLite store and installed model inference can run locally. Offline operation uses local evidence; live web discovery needs internet access and configured self-hosted services.

Does more search guarantee factual accuracy?

No. Discovery can find misleading, duplicated or outdated material. Provenance, contradiction checks and explicit abstention remain necessary. A source hash proves snapshot integrity, not truth.

Is this production-qualified?

No. This is a development preview. The 95% accuracy, coverage and citation gates remain unmet. Research calibration cannot authorize public definitive decisions.

What is the license?

The Python core is Apache-2.0. Models, datasets and optional integrations retain separate licenses. The experimental reCAPTCHA directory is separately AGPL-3.0-only; it is not part of the Apache core wheel.

Build with the WarHound ecosystem.

Use HoundSearch, HoundCrawler, HoundScraper and HoundBrowser as independently operated tools. HoundOracle focuses on factual evidence and verification; HoundHelios is a separate forecasting project.
